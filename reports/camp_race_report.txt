【7】开局机动性定理验证：满盘暗子时，明子的合法走法数 == 其邻营度
==============================================================================
  原理：开局 50 个放子位全被暗子占满，只有 10 个行营是空格。
        棋子只能走到空格（或吃掉相邻敌明子），故一枚刚翻开的明子
        的非吃子合法走法 == 它相邻的空行营数 == 邻营度。
        邻营度=0 的位（row0 / row11 底线性）翻出的子完全冻结。

  邻营度 -> 该度所有位的合法走法数（应恒等于邻营度）:
    度 3:  8 个位，合法走法数集合 = [3]
    度 2:  8 个位，合法走法数集合 = [2]
    度 1: 24 个位，合法走法数集合 = [1]
    度 0: 10 个位，合法走法数集合 = [0]

  定理反例（走法数 != 邻营度）: 无，定理成立
  完全冻结位（邻营度=0，合法走法 0）: 10 个 -> [(0, 0), (0, 1), (0, 2), (0, 3), (0, 4)]... (全部为 row0/row11)

  战略含义：
    · 首翻打在冻结位 => 该子永久无法进营，等于白损 1 手 + 1 枚子力；
    · 首翻打在度 3 黄金位 => 该子立即拥有 3 个进营选择，下一手必定占营；
    · 因此 '邻营度' 就是开局阶段的机动性/占营能力，这正是 CENTER_CAMP_FLIP_POSITIONS +150 的几何依据。

==============================================================================
【8】占营竞赛闭式模型（先手 vs 后手）与实测对照
==============================================================================
  (1) 每方可动子 = 25 - 3地雷 - 1军旗 = 21 枚
  (2) 首翻定色：先手首翻必得己方子，可动概率 = 42/50 = 0.8400
  (3) 无放回首次命中'己方可动子'期望翻子次数 E = (n+1)/(k+1) = 50/22 = 2.2727
  (4) E[T_first]  = 0.84*3 + 0.16*(1 + 2E + 2) = 3.727 ply
  (5) E[T_second] = 2E + 2                     = 6.545 ply
  (6) 结构性能差 Δ = 2.818 ply

  (7) 粗模型（单一速率 r = 1/T_second = 0.1528 营/ply）：
      先手 = (C + Δr)/2 = 5.215，后手 = 4.785，先手优势 Δr = 0.431 营
      该模型会**低估**先手优势（实测约 0.69 营），因为它把首营成本外推到了全部 10 营。

  (8) 修正模型：稳态占营速率 ρ（每 ply 每方），由基准行「T3-A 中心营优先 (+50)」标定 = 0.2796 营/ply
      等价于每营耗时 1/ρ = 3.58 ply（≈ 1.79 个己方回合）
      标定说明：ρ 不是自由拟合参数，而是 (先手营/(T_fill-T_first) + 后手营/(T_fill-T_second))/2 的直接测量值；
                模型只用它 + 理论 T_first/T_second 反推 T_fill 与占营分配。
      三条闭合公式（C = 10 营）：
        T_fill = C/(2ρ) + (T_first + T_second)/2
        先手营 = ρ·(T_fill − T_first)
        后手营 = ρ·(T_fill − T_second)
      代入理论 T_first=3.727, T_second=6.545, ρ=0.2796:
        T_fill = 23.02 ply
        先手 = 5.394 营，后手 = 4.606 营，先手优势 = ρΔ = 0.788 营
