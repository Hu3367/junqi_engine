## 1. 赛制与核心目标定义

### 1.1 为什么改成"10 营占满即停"

上一轮用完整对局（平均 210 ply）度量占营，有三个问题：

1. **信号被稀释**：占营竞赛实际只在 **ply 3~26** 之间发生（§5.1 曲线显示 ply 26 已饱和到 9.992），后 180 手与占营无关，却把方差带进统计；
2. **判和主导**：95.5% 的对称对局以循环/限步判和收场，真实胜负几乎没有统计功效；
3. **无法回答"多快"**：完整对局只能给终局占营数，给不出"占满 10 营要几手"这个最干净的策略速度指标。

新赛制直接以 **"第 10 个行营被占据的瞬间"** 为终止条件，产出三个正交指标：

| 指标 | 含义 | 稳定性（7 种子段极差/均值） |
|------|------|---------------------------|
| `占满手数 T_fill` | 双方合力填满 10 营所需 ply | **0.4%（极稳）** |
| `先手营 / 后手营` | 终止瞬间的分配 | 4.0% / 4.7%（可用） |
| `占营判据胜负` | 以占营数判胜负的胜率 | — |

> **测量夹具说明**：竞赛用 `RuleConfig(no_capture_draw_plies=0, max_plies=10**9)`。`config.py` 已明确注明 `no_capture_draw_plies` 的 `0=关闭`，这是**构造测量夹具**而非修改项目规则；`RuleConfig` 类定义、默认值与 `configs/rules.yaml` 均未改动。

### 1.2 "占营数作为唯一胜负标准"的适用边界（诚实反证）

本轮按用户设定以占营数判胜负，但上一轮完整对局的归档证据必须一并保留：

| 对局 | 占营判据 | 真实终局胜负 |
|------|---------|-------------|
| 占营优先 vs 纯随机 | **100% : 0%** | 12.4% : 0%（87.6% 和） |
| 占营优先 vs 弃营盲翻 | **81.8% : 9.9%** | 5.8% : 3.0%（91.2% 和） |
| 占营优先 vs 官方 APK 引擎 | **88.5% : 7.0%**（营数 7.63 : 1.81） | **4.0% : 5.5%**（反而略低） |

**结论**：占营数是极强的**开局主导权**指标，但**不是**有效的终局胜负代理——把它当唯一目标会让策略消极化（驻营子永不出营 ⇒ 无吃子 ⇒ 撞判和）。因此本方案采用：

> **占营数 = 开局期（ply ≤ 26）最高权重的过程指标；终局优化目标仍是 `state.winner`。**

这与 AGENTS.md "不得添加吃子、挖雷等中间奖励改变终局目标"一致。

**一句话记法**：**黄金位就是两个中心营 `@` 的"上、下、左、右"四个十字位。**

### 2.2 开局机动性定理（0 反例）

> **定理**：开局 50 个放子位全被暗子占满、10 个行营全空时，一枚刚翻开的明子的合法**非吃子**走法数 **== 其邻营度**，且每一条都指向行营。

**证明**：棋子只能走到空格或吃掉相邻敌**明子**（`state.py::_attackable` 要求 `target.revealed`）；开局唯一空格是 10 个行营；铁路滑行与工兵飞行同样被路径上的暗子阻断（`_rail_slides` 遇子即止）。故合法走法 = 相邻空营数。∎

**验证**：对全部 50 位逐一构造局面并调用 `legal_actions()`，结果 `{度3:[3], 度2:[2], 度1:[1], 度0:[0]}`，**无反例**；由 `test_opening_mobility_equals_camp_degree` 固化。

**推论**：
- **邻营度就是开局阶段的机动性/占营能力**——这是 `CENTER_CAMP_FLIP_POSITIONS +150` 的几何依据；
- 度 0 位（`row0`/`row11` 共 10 格）翻出的子**完全冻结**，等于白损 1 手 + 1 枚子力的激活机会；
- 度 1 位仍能占 1 营（不是灾难）⇒ 这解释了为什么"全程远端翻"代价小，而"首翻打死位"代价显著（§4.5）。

### 2.3 营簇星形拓扑与黄金位覆盖

10 个行营分成上下两个**营簇**，每簇是"中心营—4 角营"**星形**：

```
上簇   角营 (2,1) (2,3) (4,1) (4,3)  ── 各自只与中心营 (3,2) 相邻（行营斜人道）
       中心营 (3,2) ── 与全部 4 个角营相邻，是簇内唯一的营间机动枢纽
下簇   角营 (7,1) (7,3) (9,1) (9,3)  ── 各自只与中心营 (8,2) 相邻
       中心营 (8,2) ── 同上
```

**黄金位 ↔ 行营 辐射覆盖表**（每簇 4 个黄金位完整覆盖该簇 5 营，且每位都辐射中心营）：

| 黄金位 | 辐射的 3 个营 | 唯一非营邻居（恰为度 2 位） |
|--------|--------------|---------------------------|
| `(2,2)` **g** | `(2,1)O` `(2,3)O` `(3,2)@` | `(1,2)` |
| `(3,1)` G | `(2,1)O` `(3,2)@` `(4,1)O` | `(3,0)` |
| `(3,3)` G | `(2,3)O` `(3,2)@` `(4,3)O` | `(3,4)` |
| `(4,2)` G | `(3,2)@` `(4,1)O` `(4,3)O` | `(5,2)` |
| `(7,2)` G | `(7,1)O` `(7,3)O` `(8,2)@` | `(6,2)` |
| `(8,1)` G | `(7,1)O` `(8,2)@` `(9,1)O` | `(8,0)` |
| `(8,3)` G | `(7,3)O` `(8,2)@` `(9,3)O` | `(8,4)` |
| `(9,2)` **g** | `(8,2)@` `(9,1)O` `(9,3)O` | `(10,2)` |

**四条结构性事实**（全部由测试固化）：
1. **8 个黄金位两两不相邻** ⇒ 对手翻在任何黄金位都不会让另一黄金位吃到 `-40` 威胁扣分；
2. **中心营只有 4 个非营入口（全是黄金位）**；角营有 **7 个**非营入口 ⇒ 角营易进、中心营难进；
3. **每簇 4 个黄金位完整覆盖该簇 5 营** ⇒ 翻任一黄金位，下一手必能占营；
4. **中心营是簇内唯一营间枢纽** ⇒ `CAMP_POSITION_BONUS` 给中心营 `+50` > 角营 `+40` 与几何枢纽地位一致，不是拍脑袋参数。

> **事实 2 是全部速度结论的根源**：中心营入口稀缺（4 个），一旦被"先用黄金位上的子去占角营"消耗掉，就需要重新调度子力回到黄金位，成本急剧上升 —— 实测 ρ 塌缩 4.09 倍（§3.4）。

## 3. 数学期望推导

### 3.1 先手首翻：全 50 位打分枚举

`eval_apk_flip_root(state, action, my_color=None)` 在初始局面下逐项展开：

```
base = eval_apk_pure(state, None) = 0.0            # my_color 为 None 直接返回 0
revealed_friendly = []      → 黄金位 +150 生效
has_friendly_camp = False   → +120 不生效
is_camp(pos) = False        → +60 不生效（放子位永不是行营）
has_opp_threat = False      → -40 不生效（opp_color 为 None）
has_camp_entrance_opportunity = False → 走 else 分支 +20
```

| 位类 | 数量 | 得分 | 分解 |
|------|------|------|------|
| `CENTER_CAMP_FLIP_POSITIONS` | 6 | **170.0** | 0 + 150 + 20 |
| 其它 44 位 | 44 | **20.0** | 0 + 0 + 20 |

**分差 = 150.0**。Jitter 稳健性：`beginner` ±30 ⇒ 最坏 170−30=140 > 20+30=50。**先手首翻在三档难度下都必然落在 6 个黄金位之一**（`test_p4_pure_apk_alignment.py::test_03` 已断言）。

C++ 侧 `src_cpp/src/eval_apk.cpp:116-125` 与 `src_cpp/include/constants.h:20` 的 `CENTER_CAMP_FLIPS = {16,18,22,37,41,43}` 逐一对应 `(3,1)(3,3)(4,2)(7,2)(8,1)(8,3)`（`idx = r*5+c`），**双轨常量一致**。

### 3.2 后手首翻：条件打分

先手在黄金位 `p₀` 翻出颜色 `c`、军衔 `R` 后，后手视角：

```
base = -APK_PIECE_VALUES[R]                        # 敌明子物质，全体候选共享的常数偏移
黄金位 p（≠p₀，由事实1 保证与 p₀ 不相邻） → base + 150 + 20 = base + 170
紧邻 p₀ 的非营位 q                      → base + 20 - 40·[R 可动]
```

实测（先手首翻 `(3,1)`）：

| 先手翻出 | base | 后手黄金位分 | 后手 `(3,0)` 分 |
|----------|------|-------------|----------------|
| 红连长 (40) | −40 | **+130** | −60（−40 威胁扣分生效） |
| 红司令 (2560) | −2560 | **−2390** | −2580 |
| 红地雷 (70) | −70 | **+100** | −50（地雷正确豁免 −40） |

**两条推论**：① 由事实 1，**先手无法用首翻污染任何黄金位**，后手稳拿 `base+170`；② `base` 是常数偏移，不改变翻棋之间的排序，但会改变"翻棋 vs 明子走法"的根节点仲裁（§3.5）。

### 3.3 首占营闭式模型

每方 25 子中地雷 3 + 军旗 1 = 4 枚**永不可动**（`legal_actions` 跳过 `LEI/QI`）⇒ **可动子 k = 21**。

**引理（无放回首次命中期望）**：池中 `n` 枚、目标 `k` 枚，逐枚无放回翻开，首次命中的期望次数

\[ E(n,k) = \frac{n+1}{k+1} \]

递推 \(E(k,rest)=1+\frac{rest}{k+rest}E(k,rest-1)\)、\(E(k,0)=1\)；脚本用 `Fraction` 精确断言 `rec(21,28) == Fraction(50,22)`，**闭式与递推完全一致**。

\[
\begin{aligned}
T_1 &= \tfrac{42}{50}\times 3 + \tfrac{8}{50}\times(1+2E+2) = \mathbf{3.727\ ply}\\
T_2 &= 2E+2,\quad E=\tfrac{50}{22}=2.2727 \;\Rightarrow\; \mathbf{6.545\ ply}\\
\Delta &= T_2-T_1 = \mathbf{2.818\ ply}
\end{aligned}
\]

### 3.4 修正闭合模型：ρ 标定 + 三公式（本轮核心新增）

**上一轮的粗模型错在哪**：它假设"每营耗时 = \(T_2\)"，即把**首营成本**（含"翻到己方可动子"的 2.27 次期望翻棋）外推到全部 10 营。实际上一旦场上有 2~3 枚活子并行，每营耗时骤降。

**修正**：引入稳态占营速率 \(\rho\)（营/ply/方），由**直接测量**而非拟合得到：

\[ \rho = \tfrac12\Big(\tfrac{\text{先手营}}{T_{fill}-T_1} + \tfrac{\text{后手营}}{T_{fill}-T_2}\Big) = \mathbf{0.2796}\ \text{营/ply} \quad (1/\rho = 3.58\ \text{ply/营} \approx 1.79\ \text{个己方回合}) \]

**三条闭合公式**（\(C=10\)）：

\[
T_{fill} = \frac{C}{2\rho} + \frac{T_1+T_2}{2},\qquad
\text{先手营} = \rho\,(T_{fill}-T_1),\qquad
\text{后手营} = \rho\,(T_{fill}-T_2)
\]

**模型 vs 实测（基准行 T3-A 中心营优先，600 场）**：

| 量 | 修正模型 | 实测 | 误差 | 粗模型（单速率 0.1528） |
|----|---------|------|------|----------------------|
| \(T_1\) | 3.727 | 3.42 | +9.0% | 3.727 |
| \(T_2\) | 6.545 | 6.09 | +7.5% | 6.545 |
| \(\Delta\) | 2.818 | 2.67 | +5.5% | 2.818 |
| **\(T_{fill}\)** | **23.02** | **22.64** | **+1.6%** | — |
| **先手营** | **5.394** | **5.343** | **+0.9%** | 5.215（低估 2.4%） |
| **后手营** | **4.606** | **4.657** | **−1.1%** | 4.785 |
| 先手优势 | ρΔ = 0.788 | 0.687 | +14.7% | 0.431（低估 37%） |

**ρ 的两个制度（本轮最重要的定量发现）**：

| 制度 | 策略族 | ρ（营/ply） | 相对倍率 |
|------|--------|------------|---------|
| **通畅** | 中营优先 / 卡位优先（9 个配置） | **0.2511** | 1.00× |
| **锁死** | 角营优先 / 辐射潜力优先（3 个配置） | **0.0615** | **1/4.09** |

> 先占角营会让中心营失去唯一入口（中心营只与 4 个黄金位相邻），稳态占营速率塌缩到 **1/4.1**。这就是"中心营必须优先占"的定量依据。

### 3.5 启发常量分解与根节点"分数货币"

`eval_apk_flip_root` 的取值只可能是 `base + {+170, +140, +20, −40, −180, −200, −240}` 中的少数几项。构造性验证（`test_flip_heuristic_constant_decomposition`）：

| 情形 | 条件 | 增量 | 构造局面实测 |
|------|------|------|-------------|
| 开局首翻黄金位 | 无己方明子 | **+170** | 170.0 ✓ |
| **A 类·依托行营辐射拓荒** | `has_friendly_camp=True` | **+140**（+120 +20） | +140.0 ✓ |
| **B 类·弃营盲翻** | 有进营机会且不依托己方营 | **−200** | −200.0 ✓ |
| B′ 类·叠加敌威胁 | 上者 + 邻敌可动明子 | **−240** | −240.0 ✓ |

**A 类比 B 类高 340 分**。而根节点上与之比较的"进营走法"分数来自 `-alpha_beta(...)`，是 **depth-ply 极小化值**，实测中位仅 `base + 10.4`（初级）/ `base + 16.7`（高级），左尾可达 `base − 733`。

> **这解释了官方对齐引擎开局占营少的根因**：翻棋分是 0-ply 静态启发，走法分是极小化值，两者**货币不同源**。`+140` 的辐射拓荒翻棋必然压过 `+10` 的进营走法，于是引擎持续拓荒而不去占第 2、3 个营 —— 开局期每局仅进营 2.72~2.98 次（占营优先策略 5.25~5.63 次）。
> **但**：占营优先策略在占营数上碾压官方引擎（7.63 : 1.81）时，真实胜负反而略低（4.0% : 5.5%）。故**无证据支持"提高占营数会提升真实棋力"**，按 AGENTS.md 硬约束，本次**不建议修改**任何 `+120/+150/−200/CAMP_POSITION_BONUS` 常量。

## 4. 占营竞赛实验

### 4.1 实验设计与策略矩阵

- **脚本**：`scripts/analyze_camp_opening.py`（§9~§13）
- **样本量**：每组每方向 300 场 × 2（**同一副牌双座位**）= **600 场/组**；全因子扫描 24 配置 × 600 = 14400 场；定向对比 12 组 × 600 = 7200 场；曲线 600 场；稳定性核查 7 段 × 400 = 2800 场。**总计约 25000 场**
- **终止**：第 10 个行营被占据的瞬间
- **配对设计（本轮修正）**：非对称对抗一律用"**同一副牌局交换座位各跑一场**"。
  旧设计（不同牌局 + 交换座位）会在配对差里残留 `0.5·[Adv(S_even) − Adv(S_odd)]` 的牌局级共同模噪声，n=400 时 SE≈0.10 营，**与要测量的战术效应同量级**，会把噪声读成效应。修正后该共同模**精确为 0**（验证：15 个效应的段间 SD/单段 SE ≤ 1.01，见 §7.7）。
- **双视角**：`seat`（seat0=先手 vs seat1=后手）与 `policy`（A 策略 vs B 策略，各半局执先/执后，**配对** z 检验）

**策略的四个正交维度**（`RacePolicy`）：

| 维度 | 取值 | 语义 |
|------|------|------|
| `camp_pref` | `center` / `corner` / `radiate` / `denial` | 进哪个营：中营+50 / 角营+40 / 邻接暗子最多 / 卡位（敌可动明子一步可达） |
| `cluster` | `none` / `follow` / `split` | 翻哪个营簇：不限 / 跟随敌压力大的一侧 / 另辟敌压力小的一侧 |
| `flip_pref` | `golden6` / `golden8` / `radiate` / `near_empty` | 翻哪个位：代码 6 位 / 几何 8 位 / 依托己方营邻位(+120语义) / 紧邻空营且度最高 |
| `alternate` | `False` / `True` | True ⇒ 每占一营后强制先拓荒翻一次棋 |

**统一战术纪律**（所有 `RacePolicy` 共享，与代码常量一一对应）：

| 优先级 | 规则 | 对应代码常量 |
|--------|------|-------------|
| 1 | 有一步进空营机会 ⇒ 立即进营；**严禁营→营 闲走** | `-200` 弃营惩罚的反向；`test_p1_camp_shuttle_fix.py` 的 `-150000` |
| 2 | 向最近空营推进（多源 BFS 距离严格下降），**绝不从营里调子出来** | `camp_abandon_penalty = 250000`；行营驻守 Stand-Pat |
| 3 | 无进营也无推进 ⇒ 翻棋，位置按 `cluster`/`flip_pref` | `+150` / `+120` |

| C_alternate | 占营与拓荒翻棋交替 | 38.55 ± 0.21 | **+72.92** | 100% | 5.317 : 4.683 | +6.44 | 0.000 |

**判读**：
- **B（中营优先）压倒性最快**，22.88 ply；A（角营优先）**慢 3.78 倍**；

**两条判读（均为配对修正后的结论）**：

1. **所有反制的净占营收益都是 0**（配对 Δ ∈ [+0.003, +0.063]，\|z\| ≤ 0.56，且符号一律为 BASE 略优）。7 段池化后更精确：卡位 **+0.0071 ± 0.0545**、另辟营簇 **−0.0171 ± 0.0523**、跟随同簇 **+0.0050 ± 0.0527**（§7.7）。
   ⇒ **后手没有能提升自身占营数的反制手段。** 10 营总量固定且必然填满，先手的 Δ≈2.7~3.0 ply 时序优势决定了分配。

2. **反制的代价却高度显著**：限制翻棋营簇（follow/split/combo）使整场竞赛慢 **2.85~3.69 ply（+12.6%~+16.3%）**；而 `denial` 只改"进哪个营"、不改"翻哪个位"，**速度代价为零**（22.68 vs 22.64）。

| 优先级 | 占满 10 营手数 | vs 基准 z | 完成率 | ρ（营/ply） | 第二个中心营的平均占营序号 |

### 6.2 后手方（Second Mover）

后手的结构性劣势 **Δ ≈ 2.7~3.0 ply ≈ 0.69~0.74 个营**（先手 ≥6 营率 46.2% vs 后手 26.0%）**无法消除**。

> **本轮最重要的后手结论（更正上一轮）：所有"反制"手段对占营数的净收益都是 0。**
> 7 段池化：卡位 **+0.0071 ± 0.0545**、另辟营簇 **−0.0171 ± 0.0523**、跟随同簇 **+0.0050 ± 0.0527**，全部 \|z\| < 0.4。
> 因此后手的正确策略是**和先手完全一样地打**（黄金位首翻 + 中心营优先 + 有营就进），把全部资源用于自身节奏，而不是用于"针对先手"。

按实证性价比排序：

**① 默认（推荐）：与先手同策略 + 卡位进营（`denial`）**

进营时优先选**敌方可动明子一步可达的空营**，其次中心营，再次角营。
- 净 Δ **+0.0071 ± 0.0545（z=+0.13，无效但无害）**
- **速度代价 = 0**（22.68 vs BASE 22.64 ply）
- 推荐理由：它是唯一**零代价**的差异化手段。既然收益为 0 而成本也为 0，选它没有损失；且在对手会失误的实战中，卡位能把对手的空营直接夺走（见 ③）。

**② 不要做：为了"反制"而自我限制翻棋营簇（`split` / `follow`）**

| 手段 | 净 Δ（池化） | 速度代价 | 判定 |
|------|------------|---------|------|
| `split` 另辟营簇 | −0.017 ± 0.052 | **+2.86 ply（+12.6%）** | **纯亏** |
| `follow` 跟随同簇 | +0.005 ± 0.053 | **+3.69 ply（+16.3%）** | **纯亏** |
| `split + denial` 组合 | ≈ +0.047（单段，不显著） | +2.85 ply | 纯亏 |

原理：限制翻棋营簇会**降低翻棋命中率**（可选黄金位从 6 个减到 3~4 个），从而拖慢己方占营节奏；而由于 10 营总量固定且必然填满，拖慢只是把营让给对手，**并不会让自己多拿**。

**③ 利用先手失误（收益远大于任何常规反制）**

| 先手失误 | 识别信号 | 后手手段 | 实证收益 |
|----------|---------|---------|---------|
| 首翻打底线性死位 | ply1 翻在 `row0/row11` | 立刻在**两个簇**各翻 1 个黄金位 | 先手池化少 **0.505 营**（z=+9.60） |
| 弃营盲翻 | 先手明子紧邻空营却翻远端 | 直接抢走它相邻的空营（`denial`） | 归档对照中该失误代价达 **5.35 营** |
| 出营吃子 / 营间闲走 | 驻营子离开行营 | 立即占据腾空的营 | 每 0.85 次/局弃营 ≈ 少 0.30 营 |
| 先手角营优先 | 先手 ply3 进角营而非中心营 | **立刻抢中心营 `(3,2)/(8,2)`** | 中心营入口只有 4 个，抢下即锁死对方整簇（§4.4） |

> 第 4 行是本轮新增的、收益最大的反击点：**如果先手错误地执行"角营优先"，后手应立即夺取中心营**。角营优先会把稳态占营速率打到 1/4.09（§3.4），先手会自己把整簇锁死。

## 7. 占营数量差 Δ 的最优战术路径

> **目标函数**：\(\Delta = \text{camps}_A - \text{camps}_B\)，在第 10 个行营被占据的瞬间测量。
> **样本**：29 组对抗 × 800 场（400 副牌 × 双座位）= 23200 场；另加 15 个关键效应 × 7 种子段 × 400 场 = 42000 场池化重复。
> **脚本**：`scripts/analyze_camp_opening.py --delta`（§14 战术扫描 + §15 池化重复）。

### 7.1 规则可行性探针：哪些战术假设根本测不了

在跑任何竞赛之前，先用**项目默认 `RuleConfig()`** 构造局面核对战术的规则可行性（原子化验证，见 `section_delta_rules_probe`）：

| 战术假设 | 构造局面 | `battle()` | 是否进入 `legal_actions` | 判定 |
|----------|---------|-----------|------------------------|------|
| 排长(30) 撞 司令(2560) | `(5,2)` 红排长 → `(5,3)` 蓝司令 | `defender_wins` | **否** | **规则层不可行** |
| 工兵(80) 撞 军长(1280) | 同上 | `defender_wins` | **否** | **规则层不可行** |
| 连长(40) 撞 师长(640) | 同上 | `defender_wins` | **否** | **规则层不可行** |
| 炸弹 同尽 司令 | 同上 | `both_die` | 是 | 合法 |
| 排长 同尽 排长 | 同上 | `both_die` | 是 | 合法 |
| **营内**连长`(3,2)` → **营外**排长`(3,1)` | 行营扑杀 | `attacker_wins` | **是** | 合法（单向特权） |
| **营外**排长`(3,1)` → **营内**连长`(3,2)` | 反向 | — | **否** | **不合法**（`_attackable` 对 `is_camp(tpos)` 直接 False） |

**结论（直接否证用户假设表中的一行）**：

> **"牺牲换营 · A) 主动送死一个低价值子换取敌方一个高价值子"在 APK 规则下不可行。**
> `RuleConfig.allow_suicide_attack = False`（App 实测：禁止小子撞大子）使所有 `defender_wins` 的着法**根本不进入合法着法列表**。
> 合法的"牺牲"只有三种：**炸弹同尽**（`both_die`，可换任意敌子含司令）、**同衔相撞**（`both_die`，价值对等，无收益）、**走入敌杀区**（普通走子，下一手被敌合法吃掉）。

### 7.2 核心机制发现：吃子挤出效应

这是本轮最反直觉、也最重要的发现。

| 策略 | 合法吃子机会（次/场） | 占其回合比例 | **实际吃子（次/场）** | 转化率 |
|------|---------------------|------------|---------------------|--------|
| `D_BASE`（不吃子纯占营） | 2.19 : 1.55 | 18.9% : 13.9% | 0.00（设计如此） | — |
| **`AG_anywhere`（有吃子机会就吃）** | **2.00 : 2.01** | 17.5% : 17.6% | **0.00** | **0.0%** |
| `AG_any_out`（+ 允许驻营子出击） | 1.59 : 2.00 | 13.3% : 16.7% | **0.41** | 11.5% |
| `CT_base`（强制接触，不吃子） | 16.90 : 16.34 | 75.5% : 74.9% | 0.00 | — |
| `CT_anywhere`（强制接触 + 到处吃子） | 16.77 : 17.72 | 71.5% : 75.6% | 3.37 | 9.8% |
| `CT_all_legal`（强制接触 + 接受全部合法交换） | 14.29 : 17.11 | 59.8% : 71.6% | 4.93 | **15.7%** |

**判读**：

1. **合法吃子机会并不罕见**（低接触下每场 2.19 次，高接触下 16.9 次）。上一轮"竞赛窗口内无战斗"的推测**是错的**。
2. **但"有吃子机会就吃"的策略实际吃到 0.00 次** —— 因为**进空营是优先级 1**，而在 10 营未填满前几乎每个回合都有空营可进。吃子被**完全挤出**。
3. **唯一能落地的吃子是行营扑杀**（`AG_any_out`：0.41 次/场，其中 **99.1% 源自行营内**）。原因很干净：营内子出击用的是**另一枚子**，不与"进空营"竞争同一枚子，因此不会被挤出。
4. 即使把优先级放开到"接受全部合法交换"（`CT_all_legal`），转化率也只有 **15.7%**。

### 7.5 为什么"诱骗/暴露"对 Δ 完全无效

用户假设表里的"故意暴露高价值子力引敌入彀（如把司令走到空营旁）"，实测 **Δ = +0.019 ± 0.053（z=+0.36）**，暴露低价值子 **+0.011**，随机暴露 **+0.03** —— 三者与不暴露基准**无差别**，且**吃子数为 0.00、双方损失价值均为 0**（暴露动作根本没诱发出任何交换）。

**双重根因（信息论 + 规则）**：

1. **信息论**：翻棋规则下 `revealed=True` 的棋子身份是**公共信息**（`position_key` 只对暗子隐藏身份）。对手看到司令就知道是司令，不存在"误判"的空间。**诱骗只能作用于对手的"交换判断缺陷"，不能作用于对手的"信息缺失"。**
2. **规则**：即使对手判断有缺陷，`allow_suicide_attack=False` 也**不允许**它用小子撞司令（该着法不在 `legal_actions` 里）。唯一能吃司令的是**炸弹同尽**，而那是对手主动的、与"是否暴露"无关的决策。

**对照验证**：把对手换成 `capture_judgment=all_legal`（接受全部合法交换，即"贪交换"缺陷对手）后，暴露高价值子的 Δ 依然是 **+0.019（不显著）**。而**贪交换对手自己**因为会主动做亏损交换，反而被 `CT_all_legal` 策略赚到 **+0.2354 ± 0.0522（z=+4.51）**。

> **结论**：**收益来自"自己接受全部合法交换"，而不是"诱导对手暴露"。** 在翻棋规则下，"诱骗"这一战术范畴基本不存在；真正可操作的是**交换意愿**（是否接受 `both_die`）。

### 7.6 关键转折点：Δ 的拉开与吃子无关

用户要求采集"第几次吃子导致 Δ 发生 >1 的跳变"。**答案是：不存在这样的转折点。**

操作化定义与实测（跨 3 个种子段一致）：

| 指标 | 低接触族 | 强制接触族 |
|------|---------|-----------|
| \|Δ\| ≥ 2 的达成率 | **96~98%** | 95~98% |
| 达成 \|Δ\|≥2 **之前**的平均吃子数 | **0.00** | 0.71~1.06 |
| 全场平均吃子数 | 0.00~0.49 | 3.3~4.9 |
| 领先权易手次数（sign_flips） | **0.81 次/场** | 0.84 次/场 |

**两条判读**：

1. **Δ 拉开到 ±2 之前平均吃子数为 0.00**（低接触）/ ≈1（高接触，而全场有 3~5 次吃子）。⇒ **Δ 的拉开完全由占营节奏决定，吃子最多是次要修正项。** 之所以找不到"第 N 次吃子导致 Δ 跳变"，是因为单次占营只让 Δ 变化 ±1，而吃子**不直接改变 Δ**（它只通过削弱敌方占营能力间接起作用）。
2. **领先权平均易手 0.81 次/场**（分布：0 次 44% / 1 次 33% / 2 次 18% / ≥3 次 5%）。⇒ 竞赛过程是**反复拉锯**的，不是一边倒；但**终局分配仍系统性偏向先手**（Δ=+0.727 ± 0.10，z=+4.71）。
   > **指标定义坑**：Δ 每步只变 ±1，领先权易手必然经过 0。若只比较相邻两手（`prev>0 and cur<0`）会**完全漏计**（+1 → 0 → −1）。正确定义是"与上一个**非零** Δ 反号"。修复前该指标恒为 0.000，修复后为 0.81 —— 这是本轮第二个被自己的指标定义骗到的地方（第一个见 §0 方法论更正）。

## 9. 归档：完整对局赛制的历史结论

以下结论来自上一轮**完整对局**赛制（13 组 × 800 局 + 4 组官方引擎对照 × 200 局，平均 210 ply/局）。相应实验脚本与诊断脚本（`scripts/exp_camp_first_opening.py`、`scripts/diag_apk_blind_flip.py`）及原始报告已按需求清理，**数据在此归档，不再可直接复现**；其中与几何/常量相关的部分已由 `tests/test_camp_opening_strategy.py` 固化为构造性断言。

### 8.1 策略强度（终局占营数）

| 对照 | A 营 | B 营 | 配对差 | z |
|------|------|------|--------|-----|

| 指标 | APK 初级 | APK 高级 | 占营优先策略 |

**关键澄清**：初版纪律计数把"有合法进营却翻棋"一律记为违规，测得约 7 次/局，疑似 `-200` 失效。**原子化复算分数分解后推翻该假设**——550 个采样局面中 **99~100% 属 `+120` 依托行营辐射拓荒**（`flip−base` 实测恰为 **+140.0**，与 `+120+20` 精确吻合，且是 `test_p4_pure_apk_alignment.py::test_07` 明确断言的设计行为），**真违规仅 0~1%**（实测 `flip−base = −200.0`）。

> **方法论教训**：把"设计意图内的行为"计入违规会得到完全错误的根因判断。必须先用启发式函数复算分数增量分解，再下结论。

### 8.3 双轨对齐校验（Python vs C++）

| 档位 | 动作完全一致 | 分数等价（容许 2×jitter） |
|------|-------------|------------------------|
| beginner (±30) | 196/400 = 49.0% | **399/400 = 99.8%** |
| advanced (±0.5) | 80/150 = 53.3% | **150/150 = 100.0%** |

**判读**：动作不一致**全部**由同分候选 tie-break 与 jitter 扰动解释，估值与搜索逻辑双轨一致。⇒ **检验双轨对齐必须比分数而非比动作**，否则会假阳性。

### 8.4 已定位的低频边界缺陷（未修改）

`eval_apk_flip_root` 的 `has_camp_entrance_opportunity` 遍历己方明子时**未排除地雷/军旗**（`junqi/apk_engine.py:191-204`，C++ 侧 `eval_apk.cpp:99-114` 同）。构造性反例（已入测试）：

```
己方唯一明子 = (3,1) 地雷，邻营 (2,1)/(4,1)/(3,2) 全空
  代码判定 has_camp_entrance = True      <- 认为有进营机会
  真实合法进营走法数       = 0          <- 地雷永不移动
  eval_apk_flip_root((0,0)) = 40 − 200 = −160   <- -200 误罚
```

实战采样 550 局面中出现 **0 次**（翻出雷/旗时通常还有其它可动明子）。修复需同步 Python 与 C++ 并附二进制证据，本次不动。

## 11. 已知局限

1. **策略层实验而非引擎层实验**：`RacePolicy` / `DeltaPolicy` 都是策略层组合，未修改引擎。因此结论度量的是"占营优先原则"与"Δ 战术"的价值，**不等于**"改引擎常量后的价值"；
2. **对手模型是启发式策略，不是官方 APK 引擎**：Δ 战术研究中的对手是 `D_BASE`（不吃子）或 `CT_base`（强制接触不吃子）。真实对手（`ApkNativeAgent`）会搜索、会吃子、有 jitter，**§7.3 的效应量在真实对局中会衰减**；
3. **"接受全部合法交换"的 +0.235 依赖对手不吃子**：`CT_all_legal` 的收益来自"己方吃子、对方不吃"的不对称。若双方都接受全部交换，收益应大幅收窄——本轮**未测**该对称条件；
4. **诱骗维度的结论受对手模型限制**：我们测了"判断正确"与"接受全部合法交换"两类对手，都得到 Δ≈0。但未测"会主动用小子撞大子"的对手——因为那在 APK 规则下**不合法**，所以这个缺口无法在本规则集内填补；
5. **可分辨下限 |Δ| ≈ 0.11 营**（= 1.96 × 池化 SE 0.055）。小于此的效应本轮无法判定；10 个"不显著"效应的 95%CI 上界均 ≤ 0.16 营，可**排除** ≥0.2 营的真实效应，但不能排除 0.1 营量级；
6. **ρ 是标定参数而非推导量**：修正模型中 `T_first/T_second/Δ` 是闭式推导，但 ρ=0.2796 由基准行直接测量。因此模型对 `T_fill` 的预测（误差 +1.6%）属于"半经验"，换策略族需重新标定（角营族 ρ 仅 0.0615，强制接触族又不同）；
7. **`Δ`（首占营性能差）指标高波动**（跨种子极差 20.5%）：任何以它为判据的结论都需 ≥7 个独立种子段，单段结果不可用；
8. **竞赛赛制不判和、不限步、不判循环**：测量夹具关闭了 `no_capture_draw_plies`，因此 `T_fill` 与 Δ 都不受真实对局的判和规则影响。真实对局中 70 步无吃子判和会在 ply70 截断，而角营优先族的 `T_fill≈86` **已超过该线** ⇒ 在真实规则下角营优先会直接撞判和，其劣势比本文测得的更大；
9. **未验证四国军棋与明棋模式**：全部结论仅适用于二人翻棋（APK 翻棋模式）12×5 / 60 格棋盘。
