## 📈 数据分析建议

### 1. 开局战术研究
从 `opening_summary` 字段可以分析：
- 常见首翻棋子组合
- 开局走位模式
- 战术偏好

### 2. 玩家对战分析
统计特定玩家的：
- 胜率（分先后手）
- 常用开局
- 擅长模式
- 对阵不同对手的表现

### 3. 长局分析
筛选 `total_moves > 200` 的对局（共 84 局）：
- 持久战策略
- 残局处理技巧
- 消耗战术

### 4. 胜负因素挖掘
结合 `final_state` 提取特征：
- 剩余兵力对比
- 军旗位置安全性
- 关键棋子存活率
